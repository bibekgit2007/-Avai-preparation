# ✦ Aura Glamour Calculator

An ultra-modern, high-performance **Standard, Scientific, and Unit Converter Calculator** featuring glassmorphism, dynamic glowing ambient lighting, Web Audio synthesizer haptics, and 4 luxury themes.

---

## ✨ Glamour Features

- **💎 Luxury Theme Switcher**:
  - **Midnight Luxe**: Cyber violet, glowing obsidian & neon purple gradients.
  - **Aurora Glass**: Translucent frosted glass with teal & cyan atmospheric blurs.
  - **Rose Gold Luxe**: Haute joaillerie aesthetics with champagne & blush accents.
  - **Quantum Matrix**: Stealth dark mode with electric matrix emerald green accents.
- **🔊 Web Audio API Sound Synthesizer**: Soft clicks, tactile key feedback, and harmonic completion chimes generated natively on the fly with no external audio files required.
- **📐 Scientific & Standard Engine**:
  - Trigonometric functions (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`) in both **DEG** and **RAD** modes.
  - Exponential & Logarithmic functions (`ln`, `log10`, `e`, `π`, `xʸ`, `x²`, `√x`).
  - Factorials (`n!`), absolute values (`|x|`), reciprocals (`1/x`), percentages (`%`), parentheses.
- **💾 Memory Bank**: Instant `MC`, `MR`, `M+`, `M-`, and `MS` support with live memory status indicator.
- **📜 Calculation History**: Slide-out glass drawer storing past expressions, timestamps, with one-click tap to recall results and persistent `localStorage` storage.
- **📏 Instant Unit Converter**: Bidirectional conversion for Length, Weight & Mass, Temperature, Digital Data storage, and Speed.
- **⚡ Tactile Keyboard Shortcuts**: Full physical and numpad key mapping with visual keypress animations.

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| `0` - `9` | Insert digits |
| `.` | Insert decimal point |
| `+`, `-`, `*`, `/`, `%` | Arithmetic operators |
| `^` | Power / Exponent (`xʸ`) |
| `(` and `)` | Parentheses |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last character / function |
| `Escape` | All Clear (AC) |
